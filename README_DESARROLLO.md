# CiberIoT — plantilla temporal

Esta rama contiene una primera propuesta visual para revisar antes de publicar.

- `index.html`: estructura del sitio.
- `styles.css`: diseño adaptable a móviles y escritorio.
- `script.js`: menú móvil y mensaje de demostración del formulario.

## Pendiente antes de producción
- Confirmar servicios y textos institucionales con la empresa.
- Verificar URLs oficiales de redes sociales y datos de contacto.
- Conectar el formulario a un servicio real y probar la recepción de correos.
- Revisar privacidad y protección contra spam.

El formulario actual NO envía ni almacena mensajes. Esta rama no modifica `main`.
